# Living World RPG - Game Design Repository

## Project Overview

A multiplayer online game centered on **discovery, knowledge, and community** rather than simply leveling up. The world is intentionally mysterious. Players gradually uncover its secrets and share (or hide) information.

**Core Philosophy:** "Imagine entering a world where nobody knows everything."

## Guiding Principle

> "The player is not the chosen hero. They are one of many people living in a mysterious world, and the history of that world is written collectively through exploration, cooperation, and the actions of its inhabitants."

## Core Design Pillars

1. **Wonder** - Every session should make players ask "What happens if I do this?"
2. **Living World** - The world changes, remembers, and evolves based on player actions
3. **Knowledge** - Information is loot; maps, languages, and secrets are valuable resources
4. **Legacy Scenarios** - Hidden events triggered by invisible counters and player behavior
5. **Roles** - Different perspectives, not just classes; each role experiences the world differently
6. **Exploration** - True discovery of unexplainable geography and hidden mysteries
7. **Community** - Collective detective work; players share theories and discoveries
8. **Personal Story** - Unique journeys shaped by individual choices and actions
9. **Consequences** - Actions ripple through time; NPCs remember, villages evolve, history is written

## Development Philosophy

- **No feature bloat**: Every feature must answer "Does this make the world feel more alive or mysterious?"
- **Documentation-first**: Complete design before implementation
- **Vertical slice**: Prove core mechanics with minimal scope before expansion
- **Version-controlled design**: All documentation tracked in Git alongside code
